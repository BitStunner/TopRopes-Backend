# TopRopes Backend Architecture Docs

## Documents

- `ARCHITECTURE.md`: system context, container structure, and backend responsibility boundaries.
- `DATA_MODEL.md`: canonical domain and user-content relational model.
- `FLOWCHART.md`: read/write and migration data flow.
- `SECURITY_ARCHITECTURE.md`: trust boundaries and security controls.
- `FUTURE_ARCHITECTURE.md`: target platform evolution and migration phases.
- `FUTURE_SECURITY_ARCHITECTURE.md`: target security posture and control roadmap.

## Scope

These documents define the target backend architecture used to decouple frontend rendering from data storage and business logic.
